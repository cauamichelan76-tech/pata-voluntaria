
# 🐾 Pata Voluntária

Plataforma web para facilitar a divulgação e a adoção responsável de animais.

## 📌 Sobre o projeto

O Pata Voluntária é um projeto acadêmico desenvolvido para praticar
programação web, integração entre front-end e back-end e persistência
de dados.

## ✨ Funcionalidades

- Cadastro de animais para adoção
- Listagem dos animais cadastrados
- Filtro por status de adoção
- Informações sobre espécie, idade e descrição
- Interface responsiva
- Armazenamento local com SQLite

## 🛠️ Tecnologias

- Python
- Flask
- HTML5
- CSS3
- SQLite
- Git e GitHub

## ▶️ Como executar

1. Instale o Python 3.
2. Instale as dependências:

   ```bash
   pip install -r requirements.txt
   ```

3. Execute a aplicação:

   ```bash
   python app.py
   ```

4. Abra no navegador:

   http://127.0.0.1:5000

## 🎓 Objetivo acadêmico

Aplicar conhecimentos de Análise e Desenvolvimento de Sistemas,
desenvolvendo uma aplicação web com interface, regras de negócio
e banco de dados.

## ⚠️ Observação

Projeto acadêmico. Os animais cadastrados são dados de demonstração.
A plataforma não substitui processos de avaliação para adoção responsável.
